# 🕵️ Web Fuzzer

Инструмент для поиска скрытых страниц и директорий на веб-сайтах. 
Написан на Python для задач пентеста и разведки (OSINT).

## 🚀 Возможности:
- Поиск популярных путей (`/admin`, `/login`, `/robots.txt` и др.).
- Проверка кодов ответа (200 — найдено, 403 — защищено).
- Обработка ошибок сети (не падает, если сайт недоступен).
- **Автотесты** (pytest) для проверки корректности работы.

## 🛠️ Установка и запуск:
1. Установите зависимости:
   pip install requests pytest
   
Запустите фаззер:
python fuzzer.py

Запустите тесты:
pytest

🧪 Пример использования:
python
from fuzzer import fuzz_site
fuzz_site("https://example.com")
